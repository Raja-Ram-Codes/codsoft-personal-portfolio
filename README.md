# Raja Ram — Personal Portfolio (CodSoft Level 1, Project 1)

A responsive personal portfolio website built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure and resume-based content
- `style.css` — responsive styling and visual design
- `script.js` — mobile navigation and dynamic footer year
- `resume.pdf` — résumé download linked from the hero section

## Run locally
Open `index.html` in a browser. Internet is only needed to load the optional Google Fonts; the website layout and functionality otherwise run locally.

## Personalize before publishing
- Check that contact details and social links are correct.
- Add real projects under a Projects section once you have projects you want to showcase; none were invented for this version.
- If you prefer not to publish your phone number or email, remove them from the contact section before deploying.

## Deploy
You can publish the folder with GitHub Pages. Keep all files in the same directory so the CSS, JavaScript, and résumé download work.
